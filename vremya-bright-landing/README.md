# Время быть ярче — лендинг

Одностраничный лендинг курса-франшизы «Время быть ярче» для предпринимателей-партнёров, организующих детские мероприятия.

Стек: React + Tailwind CSS (v4), Vite. Вся разметка и логика — в `src/App.jsx`. Бэкенда нет: форма заявки на финальном CTA собирает данные в state и по кнопке «Отправить» показывает имитацию отправки.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Заглушки

В тексте оставлены плейсхолдеры `[ЦИФРА]` и `[ТЕКСТ]` там, где не хватает реальных данных (контакты, фото, точные показатели) — их нужно заполнить перед публикацией.
